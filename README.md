# Soniq

## 📖 Overview

A CSS lab that severs as, well al lab! to store some of the most reusable css layout, components and tricks. So I do not have to think about CSS everyday.

## Preview

![App Screenshot](/public/preview/soniq.png)

## 🚀 Live Demo

https://soniq-wheat.vercel.app/

## ✨ Features

- Reusable components and layouts.
- Preview the code and copy-paste it.
- Search feature to find what you want.

## 🛠 Tech Stack

- Vue 3
- CSS

## ⚙️ Installation

You have to install the latest version of node.

```bash
    git clone https://github.com/yusef-codes10/soniq
    cd soniq
    npm run dev
```
